ChatGPT広告の始め方｜費用・出稿方法・必要な準備

企画・編集：GPT広告専門店（株式会社Ikigai）公開：2026年9月18日／情報確認：2026年9月19日

ChatGPT広告は、日本の企業も自社で出稿を進められます。日本円の最低日予算は2,500円。国内2事例の平均CPCは79円・435円と幅があります。まず1商材・主要な成果・検証予算を決め、広告と計測を準備するのが始め方の基本です。

ChatGPT広告は日本から始められる。まずは商材・成果・予算を決める

「Google広告やMeta広告に加えて、新しい媒体を少し試したい」。その段階なら、最初に決めるのは次の3点です。

  • 商材：誰の、どんな検討に役立つ商品・サービスを出すか。
  • 成果：クリック、購入、問い合わせのうち、何を確かめたいか。
  • 予算：検証に使える総額と、継続を判断する日をどう決めるか。

出稿は「アカウントの確認・請求設定→広告と計測の準備→審査→配信→成果の確認」の順で進めます。日本はセルフサービスの対象国ですが、請求を受ける広告主の所在国などの条件があります。アカウント登録だけで配信が始まるわけではありません。出典：Ads Managerの提供国・利用条件

ChatGPT広告の特徴は、ユーザーが会話で伝える用途や比較条件に関連する広告を届けられることです。たとえば「賃貸住宅の玄関を、壁に穴を開けずに片付けたい」という検討に、条件に合う収納家具を紹介する設計が考えられます。これは広告設計の例であり、表示を保証するものではありません。

広告は回答と区別され、出稿しても回答を自社に有利に変更できません。また、Plus・Pro・Business・Enterprise・Eduは広告非表示です。ChatGPT全体の利用者数を、そのまま広告の到達人数と考えないようにしましょう。出典：ChatGPTでの広告FAQ

費用は最低日予算2,500円から。検証総額は別に決める

費用を考えるときは、媒体に支払う広告費と、制作・計測・運用の費用を分けます。まず目安になるのは、公式の最低日予算と、条件付きの公開実績です。

国内で公表された平均CPCは、広告支援会社Cが79円（広告費10,000円・126クリック）、広告支援会社Dが435円（広告費100,000円・230クリック）でした。この2件では79〜435円ですが、業種別の相場や自社の見積額を示す範囲ではありません。商材・入札・配信期間が異なり、両社ともCV数は非開示です。出典を確認（広告支援会社Cの配信結果）、出典を確認（広告支援会社Dの実配信データ）。

初期予算は広告費・準備費・運用費に分けて見積もる

社内で予算を相談する際は、次の内訳を揃えると比較しやすくなります。

  • 広告費：配信に使う総額と、途中で見直す条件。
  • 準備費：広告文・画像、LPの修正、計測の実装・テスト。
  • 運用費：配信確認、分析、改善、報告に必要な工数や支援費。

たとえば、クリック単価300円、問い合わせ率1%なら、問い合わせ1件あたりの広告費は30,000円です。これは説明用の仮定で、ChatGPT広告の相場ではありません。自社の許容単価と照らすと、試す意味のある水準を考えられます。

出稿前に準備する5つのもの

既存広告のLPや営業資料も材料になります。すべてを新しく作るより、今回の商材と検証目的に必要な情報を揃えましょう。

1. 広告主情報と、設定・確認を担当する人を揃える

事業者名、Webサイト、業種、ロゴ、請求先、支払い方法を用意します。特に次の点は、登録前に確認してください。

  • 国・請求通貨・タイムゾーン：作成後に変更できないため、実際の広告主に合わせる。
  • 担当者：アカウントの所有者と、制作・計測に必要な権限を持つ人を決める。
  • 商材の適格性：商品・広告表現・LPを広告ポリシーと照合する。

代理店に依頼する場合も、誰がアカウントを所有し、請求を受けるかを先に揃えます。出典：アカウント設定、広告ポリシー

2. 最初の商材は、顧客の迷いまで説明できるものを選ぶ

最初は商材や用途を絞ると、反応を見て直す箇所が明確になります。次の3点を書き出してください。

  • 誰が、どんな場面で必要とするか。
  • 購入・導入前に、価格・機能・手間の何を迷うか。
  • 自社の商品情報や実績で、どの疑問に答えられるか。

手がかりになるのは、既存広告で反応がよかった訴求や、営業でよく聞かれる質問です。収納家具なら「丈夫です」だけでなく、「賃貸でも壁に穴を開けずに置けるか」「狭い玄関で邪魔にならないか」に答えると、顧客が選ぶ理由を広告にできます。

3. 広告文・画像・LPは、同じ疑問に答える内容を用意する

広告で興味を持った人が、リンク先でも同じ説明を確認できる状態にします。

  • 価格を訴求するなら、LPで料金と適用条件を確認できるようにする。
  • 導入の簡単さを訴求するなら、LPに手順と必要な準備を載せる。
  • 用途を絞るなら、総合トップページより該当の商品・サービスページを検討する。

「クリックされたのに問い合わせがない」を改善するには、広告だけでなくLPも修正できる体制が必要です。出典：広告とリンク先の一貫性

4. 主要な成果を1つ決め、完了した行動を測れるようにする

広告で目指す成果をコンバージョン（CV）と呼びます。クリックやページ閲覧と、購入・問い合わせの完了は分けて扱います。

  • EC：購入完了を主要CVにし、売上も確認する。
  • 資料請求・問い合わせ：フォーム送信完了を主要CVにする。
  • 商談・受注まで時間がかかるサービス：広告のCVと、その後の営業結果を別々に追う。

OpenAIの標準イベントには購入・リード送信・登録・予約などがあります。サイト上の行動と送るイベントを対応させ、配信前にテストします。出典：対応する成果イベント

5. 検証総額と判定日を決め、少ない数字で結論を急がない

予算と判定日はセットで決めます。判定日には「何にいくら使い、どんな成果が出て、次に何を変えるか」を確認します。

クリックが数件集まっただけでは、問い合わせを獲得できる媒体かどうかまでは判断しにくいでしょう。問い合わせが0件でも、まだ訪問者が少ないのか、LPを読んでも申し込む理由が伝わらないのか、送信された成果を計測できていないのかで、次にやることが変わります。広告費を追加する前に、どこで止まっているかを調べます。

Ads Managerで出稿する5つの手順

通常の広告は、キャンペーン→広告グループ→広告の順に作成します。準備した情報を、次の順で設定していきます。出典：初回キャンペーンの手順

手順1：アカウントの確認と請求設定を完了する

OpenAI Ads Managerから登録を進めます。

  • 広告主情報を入力し、求められた確認手続きを行う。
  • ロゴ、請求先、支払い方法を設定する。
  • 管理画面・通知で、追加対応やアカウント審査が残っていないか確認する。

配信開始日を社内で確約する前に、広告を出せる状態かを確認しましょう。出典：アカウント設定の手順

配信目的は、表示・クリック・コンバージョンから選びます。成果最適化のoCPCはクリック課金、oCPMは表示課金です。目指す成果と、実際に費用が発生する単位を区別しましょう。

広告グループでは入札も設定します。Bid Capは成果に対する入札の上限であり、実際の成果単価の上限を保証しません。出典：成果最適化の入札と課金

手順4：広告を登録し、文字数・画像・リンク先を確認する

入稿時には、プレビューとリンク先を確認します。次は通常の広告を一括入稿する際の公式規定です。商品フィード広告は別の入稿手順を使います。

  • 見出しは最大50文字、説明文は最大100文字。
  • 画像はPNGまたはJPGの正方形で、最大1,200×1,200ピクセル。
  • LPが開き、広告で伝えた価格・条件・内容を確認できること。

一括入稿では、画像URLを外部から取得できるかも確認します。出典：広告の入稿規定

手順5：成果イベントをテストし、審査後の配信を確認する

購入や問い合わせを評価するなら、次の順で確認します。

  • LPからフォーム送信・購入まで操作し、意図したイベントが送られるか確認する。
  • 広告を審査に提出し、承認後に表示と費用が発生しているか確認する。
  • 配信後、実際の広告経由の成果が管理画面へ計上されるか確認する。

サイトのイベント送信テストと、広告に成果が紐づくかの確認は別です。UTMはGA4などで流入を見分けるもので、OpenAIの成果計測の代わりにはなりません。出典：Measurement Pixel、初回の配信確認

配信後は「広告が出ない」「CVがない」「質が合わない」を切り分ける

配信を始めると、広告費とクリック数の確認に加えて、「なぜ問い合わせにつながらないのか」を調べる仕事が出てきます。LPを直すなら制作担当、成果が記録されていないならサイトの実装担当との調整も必要です。まず問題が起きている場所を絞ると、誰に何を頼むかが決まります。

広告が出ないときは、ステータスと未完了の設定を確認する

「Not serving」などの表示がある場合は、理由を確認します。

  • 広告主の確認、請求設定、ロゴ、広告審査に未完了がないか。
  • キャンペーンの期間・配信地域・予算が意図どおりか。
  • 広告グループや広告が配信できる状態か。
  • 今週の予算枠を先に使い切っていないか。予算週は日曜から土曜で、枠を早く使い切ると有効の表示のまま配信が止まり得る。

広告文を変える前に、設定上の原因を除きます。出典：配信状態の確認

問い合わせが増えても、有効性・商談・受注まで追う

初期レポートでは、数字を3段階に分けます。

  • 配信：広告費、表示回数、クリック数、クリック率、クリック単価。
  • 獲得：主要CV、成果1件あたりの広告費。
  • 事業成果：有効な問い合わせ、商談、受注、売上。

問い合わせがあっても商材と合わないなら、訴求やLPの説明を見直します。GA4や既存媒体との比較では、期間・タイムゾーン・成果の定義を揃えます。広告クリック数とGA4のセッション数も、同じ指標ではありません。

代理店には、入稿だけでなく設計・計測・改善をどこまで頼むか決める

広告の設定からLPの修正、計測の確認まで社内で進められるなら、自社運用も選択肢です。ただ、配信後に数字が伸びなければ、原因を調べ、修正を依頼し、変更後の結果を見る時間も必要になります。既存のGoogle広告やMeta広告と並行して、その時間を確保できるかが判断の分かれ目です。代理店を検討する意味は、広告の設定だけでなく、この調査と改善を担う人を確保できることにあります。

自社は商材と顧客の判断を担い、外部とは作業と成果物を揃える

ChatGPT広告の始め方でよくある質問

最後に、初回の検討で迷いやすい点を補足します。

代理店への依頼は必須ではなく、自社出稿もできる

日本はセルフサービス対象国です。必要な条件を満たせば自社で出稿を進められます。社内で難しい設計・計測・改善がある場合に、外部支援を検討します。

既存のLPは使えるが、広告の説明とつながるか確認する

専用LPを必ず新設する必要はありません。既存ページで用途・価格・導入条件・問い合わせ方法を確認でき、成果を測れるかを基準に判断します。

少額でも試せるが、成果が出る期間は一律に決められない

最低予算と、検証に十分な予算は異なります。クリック数やCV数、検討期間を見て判断します。特定の日数や予算で成果が出るとは保証できません。
