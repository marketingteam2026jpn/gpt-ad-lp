アプリのChatGPT広告｜インストール計測とMMP連携（AppsFlyer・Adjustなど7社）の準備

企画・編集：GPT広告専門店（株式会社Ikigai）公開：2026年10月8日／情報確認：2026年10月8日

ChatGPT広告でアプリのインストールを測るには、MMP連携（AppsFlyer・Adjustなど7社）かConversions APIを使います。

本記事は、OpenAIのヘルプセンター・開発者向けドキュメント・広告ポリシー（いずれも2026年10月7日に本文を確認）に基づいています。当社はMMP連携の動作を確認していません。手順の要点は各ヘルプの記載をまとめたもので、MMP側の画面は変わることがあります。整理と提案は株式会社Ikigaiの見解です。

この記事の要点

  1. アプリのインストールと起動は、MMP連携かConversions APIで送ります。 ブラウザのPixelでは送れません。アプリ用のSDKやモバイルのデータソースは未対応で、Webのデータソースの Pixel ID を使います。対応するMMP（アプリの計測ツール）は、Adjust・Airbridge・AppsFlyer・Branch・Kochava・Singular・Tenjinの7社です。
  2. アプリの帰属はクリック基準で、MMPとAds Managerの帰属期間は別々に設定されます。 2つの画面の数字は一致しない前提で、どちらを何の判断に使うかを先に決めます。iOSの広告ID（IDFA）は送れません。
  3. リンク先には、MMPで作ったクリックURLを使います。 一方で、アプリストアへのリンクは審査に必要な内容が読めないことがあるとクローラーのヘルプは書いています。審査の前にリンクの転送先を確かめ、消費者向けの医療系アプリなど、日本向けに出せない区分に当たらないかも確認します。

読んでほしい人：スマートフォンアプリを提供していて、ChatGPT広告でインストールや登録を測りたい広告担当者・マーケティング担当者・開発者。
この記事で扱わないこと：Webサイトの計測（Pixel・UTM・GA4）は効果測定の記事、ビュー経由の成果の数え方はビュースルーの記事で扱います。

全体像：広告はChatGPTの中、成果はアプリの中

アプリの広告では、広告が表示される場所と、成果が起きる場所が別です。

  1. 利用者が、ChatGPTのアプリやブラウザで広告を見てクリックする
  2. 広告のリンク先に設定したMMPのクリックURLを経由して、アプリの入手先（アプリストアなど）へ進む
  3. アプリをインストールし、起動する
  4. MMPが、OpenAIの Pixel ID と Conversions API のキーを使って、インストールなどのイベントを送る
  5. Ads Managerの「Conversions（成果）」の指標に計上される（MMPのヘルプによると、反映まで24〜48時間）

送れるアプリのイベントと送り方

開発者向けの対応イベントの一覧には、アプリ専用のイベントが2つあります。

イベント名

内容

送り方

app_installed

アプリのインストール

Conversions APIのみ。action_source を mobile_app にする

app_opened

アプリの起動

同上

registration_completed など他の標準イベント

登録・体験開始・購入など

MMPでアプリ内のイベントを対応づけて送る（標準イベントかカスタムイベント）

開発者向けの Conversions API・対応イベント・Measurement Pixel の説明には、次の4点が書かれています。

  • app_installed と app_opened は、ブラウザのPixelでは送れません。 サーバーから Conversions API で送ります
  • Pixel ID は、既存のWebのデータソースのものを使います。 アプリ用のSDKの設定と、モバイルのデータソースは現在サポートされていません。アプリだけを提供する事業者でも、Ads Managerの成果（Conversions）の画面でWebのデータソースを作り、Pixel ID を用意することになります（当社の解釈）
  • Androidの広告ID（GAID）は送れますが、iOSの広告ID（IDFA）は対応していません。 一致に使える情報として、ハッシュ化したメールアドレスや電話番号なども送れます
  • 送るイベントの時刻は、直近7日以内である必要があります

もう1つ、OpenAIのヘルプは、成果のデータは法令と利用規約で認められる範囲で送り、サイトやアプリで集めるデータを利用者に分かりやすく説明し、法令で必要な同意を得てから送るよう求めています。アプリの計測で外部にデータを送る前に、自社のプライバシーポリシーと同意の設計を確認します。

MMP連携の準備と、7社のリンクの置き方

準備するもの

MMPのヘルプが挙げる準備は次のとおりです。

  • 有効なAds Managerのアカウント
  • Webのデータソースの Pixel ID と、Conversions API のキー（どちらもAds Managerの成果の画面で発行）
  • MMP側で、アプリまたはWebサイトの設定が済んでいること
  • MMP側で連携を設定できる権限
  • ChatGPT広告に送る標準イベント・カスタムイベントの一覧

7社ごとの手順の要点

連携の手順はMMPごとに違います。特に間違えやすいのは、MMPで作ったリンクをAds Managerのどこに置くかです。ヘルプの記載を、リンクの扱いを中心にまとめました。

MMP

MMP側で行うこと（要点）

広告に使うリンクと置き方

Adjust

Campaign Lab で ChatGPT Ads を追加。Pixel ID・APIキー・インストールのイベント名を入れ、Action Source を Mobile App に

作成したクリックURLを該当のキャンペーンで使う

Airbridge

Ad Channel Integration で ChatGPT Ads を選び、Postback Keys に Pixel ID・APIキー

トラッキングリンクを「?」で分け、前半を Default Ad Destination URL、後半を Tracking parameters の欄へ

AppsFlyer

Partner Integrations の Marketplace で ChatGPT Ads (OpenAI) を連携。アプリ内イベントのポストバックを対応づけ

帰属リンク（attribution link）を使い、動的パラメータは Tracking parameters の欄に残す

Branch

Performance Product の有効化が前提。OpenAI Ads の連携で Pixel ID・APIキー、全イベントの送信を有効に

Branch Ad Link をリンク先URLに使い、マクロは Landing page query parameters の欄へ。送るイベントごとにAds Managerで成果イベントを作り、キャンペーンに紐づける

Kochava

Campaign Manager でトラッカーを作り、メディアパートナーを ChatGPT Ads（iOS／Android／Web）から選ぶ。イベントごとに Pixel ID・APIキー

トラッカーの Click URL を広告のリンク先に使う

Singular

Partner Configuration で OpenAI Ads (ChatGPT) を追加し、Pixel ID・APIキー、イベントを対応づけ

Partner 型のリンクを作り、Click-through Tracking Link を該当のキャンペーンで使う

Tenjin

OpenAI Ads のチャネルとコールバックを設定。APIキーは「Bearer」と半角スペースに続けて入力し、インストールのコールバックを有効に

Click Tracking URL の全体を広告の「Link」欄に貼り、保存の前に「Move to tracking parameters」を押す。広告ごとに繰り返す

AppsFlyerは、Webサイトについては Web SDK から Conversions API へイベントを転送する設定も案内しています。

欄の名前は、ヘルプの中でも「Tracking parameters」（AppsFlyer・Airbridge・Tenjin）と「Landing page query parameters」（Branch）の2通りで書かれています。Ads Managerの効果測定のヘルプは、キャンペーン・広告グループ・広告の編集画面の「Landing page query parameters」でパラメータを付けると説明しています。自社の画面で欄の名前と位置を確かめてください。

同じキーのパラメータを、リンク先URLとキャンペーンなど複数の場所に重ねて設定しないことも大切です。ヘルプでは、広告のURLに書いた値が最も優先され、広告・広告グループ・キャンペーンの設定はそれを上書きしません。

リンク先がアプリストアに転送される場合

MMPのヘルプは、MMPで作ったリンクを広告のリンク先に使うよう案内しています。一方、クローラーのヘルプには次の記述があります。

Use a directly reachable web landing page whenever possible. App-store links, deep links, documents, or destinations that require an app, login, region-specific access, or unsupported redirects may not provide enough crawlable content for validation or review.

当社訳は「可能な限り、直接開けるWebのLPを使ってください。アプリストアへのリンク、ディープリンク、文書、アプリやログイン・特定の地域からのアクセスが必要なリンク先、対応していない転送は、検証や審査に必要な内容を読み取れないことがあります」です。MMPのリンクの転送先がアプリストアの場合に審査でどう扱われるかは、どちらのヘルプにも書かれていません。

当社は、審査に出す前に次を確かめることを勧めます。

  • リンクを開いたとき、最終的にどのページへ着くか（Webの紹介ページか、ストアか）
  • MMP側で、転送先や、ストア以外の環境で開いたときの行き先を設定できるか（MMPのドキュメントで確認）
  • 否認された場合の否認理由（Ads Managerで「Not serving」の広告にカーソルを合わせる）

ChatGPTのiOSアプリ内のブラウザで広告のリンクを確かめるときは、共有からURL全体をコピーしてパラメータを確認します。画面に出るホスト名だけでは、完全なURLは分かりません。

帰属はクリック基準：MMPとAds Managerの数字の違い

MMPのヘルプは「この連携によるモバイルアプリの帰属はクリック基準」と明記しています。開発者向けの Conversions API の説明も、アプリのイベントとMMP連携の帰属はクリック基準のままだとしています。Ads Managerではビュー経由（広告を見て、クリックせずに起きた成果）の計上もありますが、アプリのイベントには当てはまらないと読めます（当社の解釈）。

なお、Webのビュー経由を成果の合計（Conversions）に含めるかは、開発者向けのPixel・Conversions APIのページとヘルプの記述が食い違っています。Webとアプリの両方を測る場合は、自社のAds Managerで帰属期間の設定と、クリック経由・ビュー経由の内訳を確かめてください（ビュースルーの記事）。

数字が合わない主な理由は次の3つです。

理由

内容

帰属期間が別

MMPの帰属期間とイベント共有の設定はMMP側で行い、Ads Managerは自身の帰属設定（クリック7・14・30日）でレポートする

反映の時間

Ads Managerへの反映は24〜48時間。直近の数字は後から変わる

数える対象

MMPは、自社が使う他の広告媒体もまとめて帰属を判定するため、ChatGPT広告に割り当てる件数がAds Managerと変わり得る（当社の見方。各MMPの設定による）

当社は、媒体の最適化と配信の調整にはAds Managerの数字を、他の媒体との比較や予算配分にはMMPの数字を使うといった形で、判断ごとに使う数字を先に決めることを勧めます。

連携がうまくいかないときの確認順も、ヘルプに挙がっています。連携が有効か、Pixel ID とAPIキーが正しいか、イベント名の対応づけが正しいか、キャンペーンに正しいリンクを使っているか、成果イベントがキャンペーンに紐づいているか、を確かめます。テストは新しい広告のクリックで行い、反映を24〜48時間待ちます。

配信面の「iOSアプリ」「Androidアプリ」はChatGPTのアプリ

キャンペーンの配信面（プラットフォーム）は、Ads Managerで Android app・Android web・Desktop web・iOS app・iOS web の5つから選べます。開発者向けの説明では、これは「キャンペーンを配信できるChatGPTの面」で、iOS app はChatGPTのiOSアプリ、Android app はChatGPTのAndroidアプリを指します。広告主のアプリの対応OSを選ぶ設定ではありません。iPhoneのブラウザでChatGPTを使う人は、アプリではなくWebの面に入ります。

iOS版しかないアプリでも、ChatGPTを使う端末を配信面で選ぶことはできます。例えば、iOS app と iOS web に絞れば、Androidの端末でChatGPTを使う人への配信を避けられます（当社の提案）。配信面を絞ると母数も減るため、最初は広めにして、Insightsの Platform 別の数字を見てから絞る方法もあります。指定できる条件の一覧はターゲティングの記事で扱っています。

既存のユーザーを除外したい場合は、カスタムオーディエンスを使えます。メールアドレス・電話番号（ハッシュ化も可）・GAIDのリストから作れ、除外なら一致したユーザーが2万5,000人未満でも使えます。ヘルプが挙げる識別子に、IDFAは含まれていません。

日本向けに出せる・出せないアプリの区分

アプリも、広告ポリシーと規制領域の国別表の対象です。日本の広告主が特に確認したい区分を抜き出しました。アプリの機能と表の区分の対応は原文に書かれていないため、左の列の当てはめは当社の見方です。

アプリの種類（例）

原文の扱い（日本を含む米国以外）

消費者向けの医療・健康管理アプリ

国別表「消費者向けの医療機器・ウェアラブル・アプリ」は不可。医療的な主張のない運動・ウェルネスのアプリが当たるかは書かれていない

Webに送る設計も選べる：公式事例の計測の条件

アプリを持っていても、インストールを成果にする必要はありません。公式事例のAI語学学習アプリP（AIと会話して言語を練習できるアプリ。Web・モバイルで提供）は、広告からWebサイトへ送り、無料体験を始められるようにしたと書いています。同社が公表した数字は、どちらもWebキャンペーンの広告主の社内推計です。ROASは比較相手のチャネルと同じUTMのラストクリック計測、体験開始の単価はPixelとConversions APIで記録したイベントによるもので、MMPでインストールを測った事例ではありません（数字と条件は教育・語学事例の記事）。

Webで体験や登録を始められるサービスなら、Pixel・Conversions API・UTMという、Webサイトと同じ計測で始める方が準備は少なく済みます（当社の見解）。一方、アプリでしか使えないサービスや、インストール後の行動で価値が決まるサービスでは、MMP連携でインストールとアプリ内のイベントを送る設計になります。どちらにするかは、「どこで最初の成果が起きるか」で決めます。

この記事で分からないこと

  • MMPのリンクの転送先がアプリストアの場合に、審査でどう扱われるか。 MMPのヘルプとクローラーのヘルプの両方に記載がありません
  • app_installed を成果最適化（Conversion optimization）の目標に選べるか。 標準イベントの一覧にはありますが、成果最適化のヘルプにアプリのイベントの例は書かれていません。Ads Managerの画面で確かめます
  • ChatGPTのアプリで広告をクリックしたとき、ストアがどう開くか。 iOSアプリ内のブラウザで開くことは分かりますが、ストアへの遷移の挙動は書かれていません
  • 日本のアカウントで7社の連携がすべて使えるか。 当社は連携を操作していません

MMP連携のチェックリスト

  • [ ] アプリの種類が、日本向けに出せない区分に当たらないか確かめた
  • [ ] Webのデータソースの Pixel ID と、Conversions API のキーを用意した
  • [ ] MMP側で ChatGPT Ads（OpenAI Ads）の連携を有効にし、Pixel ID とキーを入れた
  • [ ] 送るイベント（インストール・登録・購入など）を、標準イベントかカスタムイベントに対応づけた
  • [ ] Ads Managerで成果イベントを作り、キャンペーンに紐づけた
  • [ ] MMPのリンクを、ヘルプどおりの欄に置いた（動的パラメータの欄を含む）
  • [ ] 同じキーのパラメータを複数の場所に重ねていない
  • [ ] リンクの最終的な転送先と、審査の結果を確かめた
  • [ ] 新しい広告のクリックでテストし、24〜48時間後にAds ManagerとMMPの両方で確かめた
  • [ ] 判断ごとに、Ads ManagerとMMPのどちらの数字を使うかを決めた
  • [ ] アプリで集めるデータの説明と同意を、プライバシーポリシーで確認した

よくある質問

Q. アプリのSDKを入れれば、ChatGPT広告のインストールを測れますか。 OpenAIのアプリ用SDKは現在サポートされていません。MMP連携を使うか、自社のサーバーから Conversions API で app_installed を送ります。どちらの場合も、Webのデータソースの Pixel ID を使います。

Q. 対応しているMMPはどこですか。 2026年10月7日時点のヘルプで対応しているのは、Adjust・Airbridge・AppsFlyer・Branch・Kochava・Singular・Tenjinの7社です。ヘルプは、対応先が増えたら更新するとしています。

Q. アプリのインストールを成果最適化の目標にできますか。 app_installed は対応イベントの一覧にあり、開発者向けドキュメントは標準イベントを成果最適化の目標に使えると説明しています。ただし成果最適化のヘルプにはアプリのイベントについての記載がなく、選べるかは書かれていません。Ads Managerの設定画面で確かめてください。選べない場合も、目的を「クリック」にしたキャンペーンで成果を計測できると、開発者向けドキュメントは説明しています。

Q. 配信面で「iOS app」を選べば、iPhoneユーザーにアプリを宣伝できますか。 「iOS app」は、ChatGPTのiOSアプリでの表示を指します。iPhoneのブラウザでChatGPTを使う人は「iOS web」です。iOS版のアプリを宣伝するなら、iOS app と iOS web を選ぶとChatGPTをiPhoneで使う人に絞れます（当社の提案）。

Q. iOSのインストールも、Androidと同じように測れますか。 MMPのヘルプには、KochavaでChatGPT Ads – iOSのパートナーを選ぶ手順のように、iOS向けの設定も含まれています。ただし帰属はクリック基準で、Conversions API で送れる広告IDはAndroidのGAIDだけです。iOSのIDFAは対応していません。iOSでどこまで一致させられるかは、MMP側の仕組みにもよります。

まとめ

  • アプリのインストール・起動は、MMP連携（7社）か Conversions API で送る。Pixelは非対応
  • アプリ用SDKとモバイルのデータソースは未対応。Webのデータソースの Pixel ID を使う
  • 帰属はクリック基準。MMPとAds Managerの帰属期間は別で、数字は一致しない前提で使い分ける

  • 消費者向けの医療系アプリ・決済・暗号資産・出会い系などは日本向けに出せない区分。Webで体験できるならWebに送る設計も選べる
