SaaS・ITサービスのChatGPT広告｜無料トライアル・デモ申込の成果の決め方と計測の設計

企画・編集：GPT広告専門店（株式会社Ikigai）公開：2026年11月4日／情報確認：2026年11月4日

SaaS・ITサービスのChatGPT広告は、無料登録・トライアル開始・デモ予約・有料契約のどれを成果にするかで、最適化と評価が変わります。

本記事は、OpenAIの公式ヘルプ、広告ポリシー、開発者向けドキュメント、OpenAIが掲載した公式事例2件（いずれも2026年11月4日に取得）に基づいています。事例の企業名は伏せています。成果の段階の決め方、計測の設計、広告文の例は株式会社Ikigaiの見解で、例は説明のための架空のものです。

この記事の要点

  1. 最初に、どの段階を成果にするかを決めます。 無料登録・トライアル開始・デモ予約・問い合わせ・有料契約には、それぞれ標準イベントがあります。成果最適化で選べるのは1キャンペーンに1つです。製品から使い始めてもらう商材はトライアル開始や登録、営業が商談する商材はデモ予約や問い合わせから始めるのが現実的です（当社の提案）。
  2. 有料化や商談化をConversions APIで送るなら、登録のときに広告の参照値（oppref）を保存しておきます。 送れるのは行動から7日以内の時刻のイベントで、帰属期間はクリック経由で最長30日です。Ads Managerの売上・ROASの列は購入（order_created）だけから計算され、有料契約のイベントの金額は入りません。
  3. 広告文とヒントは、「どの作業・どの課題のためのツールか」を具体的に書きます。 公式事例2件は、用途ごとのキャンペーンや、すぐ試せる案内を使っています。リンク先は、ログインなしで開ける用途別のページにします。機能・価格・他社との比較の根拠のない表現は、ポリシーで認められていません。

読んでほしい人：SaaS・クラウドサービス・開発者向けツールなどIT系の商材で、ChatGPT広告を試す広告担当者。トライアルやデモの申込を増やしたいマーケティング担当者。
この記事で扱わないこと：B2Bの公開事例の読み比べはB2B事例の記事、Conversions APIの実装はConversions APIの記事、CRMとの連携はHubSpot連携の記事で扱います。

SaaS・ITサービスは出稿できるか

広告ポリシーは、初期のテスト期間の広告を、主に消費者向けの分野（生活・家庭用品、地域のサービス、旅行・体験、デジタル製品・教育など）に限るとしています。法人向けのSaaSを名指しした記載はありません。一方、OpenAIはフォーム作成SaaSや開発者向けAPI企業の事例を公式に掲載しており、規制の厳しい分野の国別表でも、金融のソフトウェア（Financial software）と、医療のソフトウェア・基盤（Health software and infrastructure）は、米国以外でも「可」とされています。ソフトウェアやクラウドサービスは「デジタル製品」として出稿を検討できる分野と当社は読んでいますが、審査の結果は保証されません。

ただし、IT系の商材でも次の点は確かめます。

確かめること

ポリシーの記載

機能・価格・成果・他社との比較

機能、価格、成果、提携、他の製品や会社との比較について、根拠のない主張は認められない

他社の名前やロゴ

自社が持つか、使う許可を得た商標・ロゴだけを使える。他社を装う・推薦を受けたように見せるのは不可

生成AIのツール

性的な画像を生成・加工するツールや、成人向けのAIの話し相手のアプリは不可

金融・医療に近い機能

金融商品や取引を勧めない家計簿アプリや一般的な財務ソフトは原則として可。病気の予防・診断・治療に関わる主張は制限される

AIを使った製品は、広告の画像に会話の画面を使いたくなります。ChatGPTの回答に見える画像は避けるのが安全です（当社の見解）。審査の結果は、ポリシーの読み方だけでは決まりません。審査の流れは審査の記事で扱っています。国内の規制（景品表示法など）への適合は、OpenAIの審査とは別に確かめます。

もう1つ、法人向けの商材で知っておきたい点があります。広告が表示され得るのはFreeとGoのプランで、ChatGPT BusinessやEnterpriseなど法人向けのプランには広告が出ません。勤務先の法人プランでChatGPTを使う担当者には、その環境では広告が表示されないことになります（表示対象とプライバシーの記事）。

最適化より、評価と社内の報告に使う

当社は、成果最適化に使う成果と、評価に使う成果を分けることを勧めます。最適化には件数が見込める段階を1つ選び、その先の段階は自社のデータ（CRMや製品のデータベース）で追います。

  • 製品から使い始めてもらう商材（無料プランやトライアルから始まる）：最適化はトライアル開始か登録。評価は有料化の率まで
  • 営業が商談する商材：最適化は問い合わせかデモ予約。評価は商談化と受注まで

成果最適化では、1つのキャンペーンに選べる標準イベントは1つで、作成後に変えられません。カスタムイベントは選べません。選び方は成果最適化キャンペーンの記事で扱っています。

有料化・商談化を計測する：Conversions APIの使い方

登録やトライアル開始は、完了ページのPixelで計測できます（Pixelの記事）。一方、有料契約の開始や商談化は、数日から数週間後に、製品のサーバーやCRMの中で起きます。これをChatGPT広告に届けるにはConversions API（サーバーから成果を送る仕組み）を使います。SaaSで特に効く制約は3つです。

もう1つ注意があります。APIの説明では、キャンペーンの成果のレポートは、キャンペーンに付けた成果イベントの設定で行われます。成果最適化のキャンペーンに付けられる設定は1つだけです（クリック・表示のキャンペーンは複数付けられる）。そのため、トライアル開始で最適化するキャンペーンでは、有料化のイベントを送っても、そのキャンペーンの成果としては数えられないことがあり得ます。Ads Managerの画面で同じかはヘルプに書かれていないため、有料化はCRMでも追えるようにしておきます（当社の提案）。

opprefは、広告のクリックでリンク先のURLの末尾に付く参照値です。Pixelはこれを自動で保存しますが、サーバーから送るときは自社で受け取って渡す必要があります。ヘルプは、opprefのないイベントも含め、送ってよい成果はすべて送るよう勧めています。照合用の情報は、正規化してハッシュ化したうえで、必要な同意を得て送ります（Conversions APIの記事）。

有料契約の金額は、売上・ROASの列に入らない

ヘルプによると、Ads Managerの「Order Created Sales」「Order Created ROAS」の列は、帰属した order_created（購入の完了）のイベントだけから計算されます。ほかの標準イベントやカスタムイベントは、この列に入りません。subscription_created に金額を付けて送っても、Ads Managerの売上・ROASの列には反映されないことになります。

SaaSの広告の採算は、月額の売上や契約期間の売上で見ることが多いと当社は考えます。当社は、ROASや顧客獲得単価を、Ads Managerではなく自社のCRMや分析の仕組みで計算することを勧めます。広告から来た顧客を見分けるには、UTMとopprefを顧客の記録に残します。1件の有料化を order_created と subscription_created の両方で送ると、同じ成果を2回数えることになるため避けます（当社の見解）。

始め方のドキュメント

ヘルプは、ある顧客層に届けたいということだけでは関連性にならない、とも書いています。「大企業の情報システム部門」のように対象者の属性だけを書くより、その人が抱える作業や課題を書きます（コンテキストヒントの記事）。

広告文は用途ごとに、互いに違う切り口で

広告のヘルプは、何を提供し、誰向けで、いつ役立つかを説明する、価値の分かる文を勧めています。また、1つの商材に複数の、互いに違う切り口の広告を用意するよう書いています。SaaSなら、機能の数ではなく、用途ごとに広告を分けるのが分かりやすい方法です。

リンク先はログイン不要の、用途別のページ

ヘルプは、トップページではなく最も関係のあるページへリンクするよう勧めています。SaaSで注意したいのは、アプリのログイン画面や登録の画面を直接リンク先にすることです。審査のクローラーのヘルプは、サインイン・CAPTCHA・ブラウザの確認を経ずにLPへ届くことを求め、ログインやアプリが必要なリンク先は審査に足る内容を読めないことがあると書いています。用途別の説明のページに、登録やトライアルのボタンを置く形にします（クローラー許可の記事）。

この記事で分からないこと

  • 成果最適化に、どの段階のイベントを選ぶと成果が出やすいか。 公式資料は「目標を最もよく表し、十分な件数があるイベント」とだけ書いています
  • 有料化のように時間がたって起きる成果を、最適化がどこまで使えるか。 最適化に使われる帰属期間は書かれていません
  • subscription_created の金額が、レポートのどこかに表示されるか。 売上・ROASの列に入らないことだけが書かれています
  • 成果最適化のキャンペーンで、選んだイベント以外（有料化など）がAds Managerのレポートに出るか。 APIの説明では、レポートはキャンペーンに付けた設定で行われ、成果最適化のキャンペーンに付けられる設定は1つです
  • 広告からChatGPTの中のアプリ（プラグイン）へ直接誘導する方法。 ACの事例に体験の記載はありますが、ヘルプに手順はありません
  • 法人向けのSaaSで、FreeとGoの利用者のうち仕事の相談をしている人の割合。 公開されていません

SaaSの成果定義シート（テンプレート）

  • [ ] 商材の形を決めた（製品から使い始める／営業が商談する）
  • [ ] 最適化に使う成果を1つ決めた（例：trial_started）
  • [ ] 評価に使う成果を段階ごとに決めた（登録→トライアル→デモ→有料契約）
  • [ ] 各段階をどの仕組みで計測するか決めた（Pixel・Conversions API・CRM）
  • [ ] 登録のときに、opprefと照合用の情報を顧客の記録に保存する
  • [ ] 有料化・商談化のイベントを、行動から7日以内に、元の時刻で送る仕組みにした
  • [ ] クリックから有料化までの日数の分布を確かめ、30日を超える分の追い方を決めた
  • [ ] ROAS・顧客獲得単価は自社の仕組みで計算する（Ads Managerの売上の列は購入だけ）
  • [ ] 同じ成果を2つのイベントで二重に送っていない
  • [ ] 広告文・LPで、機能・価格・他社との比較に根拠のない表現を使っていない
  • [ ] リンク先が、ログインなしで開ける用途別のページになっている
  • [ ] 判定の日を、トライアルの期間や商談の期間に合わせて決めた

よくある質問

Q. 無料トライアルとデモ申込、どちらを成果にすべきですか。 商材の売り方で決めます。製品を触ってから買う商材で、トライアルから有料化の率が分かっているなら、件数の多いトライアル開始を成果にし、有料化は計測で追います。営業が説明して契約する商材なら、デモ予約が受注に近い成果です。デモ予約の件数が少なすぎて判断できないときは、問い合わせ（lead_created）から始めます（当社の提案）。どちらの場合も、最適化に使えるのは1キャンペーンに1つの標準イベントです。

Q. 有料契約の売上で、ChatGPT広告のROASを見られますか。 Ads ManagerのROASの列（Order Created ROAS）は、購入の完了（order_created）のイベントだけから計算されます。有料契約の開始（subscription_created）に金額を付けても、この列には入りません。当社は、CRMや分析の仕組みで、広告から来た顧客の売上を集計してROASを計算することを勧めます。月額の商材なら、どの期間の売上で計算するかも先に決めます。

Q. ChatGPTの中で動く自社のアプリ（プラグイン）に、広告から誘導できますか。 フォーム作成SaaS ACの事例には、ChatGPTの中で同社の機能を使って、フォームの作成・編集・分析ができる体験を試したと書かれています。ただし、広告のリンク先をChatGPTの中のアプリにする手順は、2026年11月4日時点の公式ヘルプに見当たりません。ヘルプは、できるだけ直接開けるWebのページをリンク先にするよう勧めています。

Q. API・SDKなど開発者向けのツールでも出せますか。 開発者向けAPI企業Qの公式事例があり、ポリシーにも開発者向けのツールを一律に禁じる記載はありません。事例は、開発者の問いが「アプリにチャットを追加するには」のような作業の依頼に近いと説明し、Qはその問いに寄せた短い広告文と「無料で始める」の案内を使っています。リンク先は、ログインなしで読める始め方のページにします。審査の結果は保証されません。

Q. 営業担当の代わりに、AIが質問に答える広告はありますか。 企業のAIの担当者と会話できるSponsored Agentsという形式がありますが、2026年11月4日時点では、選ばれた広告主だけが使える限定アルファのテストです。早期の利用の申し込みも受け付けていないとヘルプに書かれています。提供状況は表示形式と最新動向の記事で扱っています。

まとめ

  • SaaSの成果は、登録・トライアル・問い合わせ・デモ予約・有料契約に分け、標準イベントに当てはめる
  • 最適化には件数が見込める段階を1つ選び、その先は計測で追う（当社の提案）
  • 有料化をConversions APIで送るなら、登録のときにopprefと照合用の情報を保存する。送れるのは7日以内の時刻のイベント
  • Ads Managerの売上・ROASの列は購入だけから計算される。SaaSのROASは自社で計算する
  • ヒントは「誰の、どの作業か」、リンク先はログイン不要の用途別のページにする
  • 公式事例2件は、用途に合わせた広告・LPと、クリックの先の評価が共通点。数字は目安にしない

自社のSaaSで、どの段階を成果にして何から試すかを整理したい場合は、登録からトライアル・有料化・商談化までの段階ごとの件数の目安と、使っている計測ツール・CRMをお手元に用意のうえ20分の無料相談をご利用ください。
