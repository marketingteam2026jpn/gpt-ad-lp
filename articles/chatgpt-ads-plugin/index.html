ChatGPT広告のAds Managerプラグイン｜ChatGPT・Codexから広告を作る・分析する

企画・編集：GPT広告専門店（株式会社Ikigai）公開：2026年10月29日／情報確認：2026年10月29日

この記事の要点

  1. プラグインは、ChatGPTやCodexとの会話でAds Managerを操作する仕組みです。 広告案の作成、設定の変更、成果の分析、配信しない原因の切り分け、改善案のレビューができます。使えるのは、接続したAds Managerのユーザーがアクセスできるアカウントと、その役割で許された操作だけです。
  2. アカウントを変える操作は、内容を示して承認を得てから実行されます。 分析・レビュー・原因の切り分けは読み取りだけで、定期的なレビューも自動では変更しません。請求・支払い・税・本人情報・異議申し立てはAds Managerで行い、売上やROASは出しません。
  3. 当社は「読む・下書きする」に使い、「公開・予算・入札」は人がAds Managerで確かめることを勧めます。 分析だけの担当者は閲覧者（Viewer）の役割で接続し、作った広告は停止の状態で保存する運用にします。日本のアカウントで使えるかと、使えるChatGPTのプランは、2026年10月29日時点で確認できていません。

読んでほしい人：ChatGPT広告を運用していて、レポートの作成や設定の確認の手間を減らしたい担当者。社内や代理店でプラグインを使わせるか、どこまで任せるかを決めたい責任者。
この記事で扱わないこと：CSVの一括入稿とAdvertiser APIは一括入稿とAPIの記事、Ads Managerの画面での操作はAds Managerの使い方の記事で扱います。

Ads Managerプラグインとは

OpenAIは2026年9月16日の発表で、ChatGPTの中で自然な言葉の指示によってキャンペーンを作成・更新・分析できる「Ads Managerプラグイン」の順次提供（rolling out）を始めたと書いています。サイトや説明文をキャンペーンにし、成果を読み取り、次にやることの提案を受けられる、という説明です。

2026年10月29日時点で、公式の資料は次の3つです。

資料

書かれていること

ヘルプ「Use the ChatGPT Ads Manager plugin」

できること、承認の仕組み、制限、よくある質問。10月7日と10月29日の本文に違いはありません

プラグインの紹介ページ（OpenAIのサイト）

開発元はOpenAI、分類は「Operations」、機能は「Interactive・Read・Write」。できることの概要（変更履歴の分析を含む）、含まれるスキル（作業ごとの手順）の名前、導入の3つの手順

プラグインの設定ガイド（プラグイン全般の説明）

使える場所、導入のしかた、権限とデータの扱い

紹介ページに名前が出ているスキルは、Manage Ads Account、Ads Manager Actionable Review、Create Ads、Business Agent Setup、Ads Manager Delivery Recovery、Manage Ads Entities、Ads Manager Help、Ads Manager Insights の8つで、ほかに「6 more」とあります。それぞれの中身は書かれていません。Business Agent Setup という名前がある一方、ヘルプの「Current limitations」は「ビジネスエージェントの広告の作成には対応していない」と書いています。このスキルで何ができるのか、誰が使えるのかは、どちらの資料にも書かれていません。当社は、ヘルプの記載を優先し、プラグインでビジネスエージェントの広告は作れないものとして扱います（当社の見解）。

使える場所と、日本での提供状況

設定ガイドはプラグイン全般について、ChatGPTの Chat と Work（web・デスクトップアプリ・モバイル）と、Codex（ChatGPTのデスクトップアプリとCodex CLI）で使えると書いています。CodexのIDE拡張には対応していません。Ads Managerプラグインの紹介ページは、使い始めの手順として「ChatGPT Work か Codex で新しいチャットを始める」と書いています。

紹介ページは「使えるかは、プラグイン、プラン、ワークスペースの設定による」と書いています。どのChatGPTのプランで使えるか、国による違いがあるかは書かれていません。Ads Managerのセルフサーブは、国別の一覧で日本が「Available」です。ただし、日本の広告アカウントでプラグインのどの操作まで使えるかは、公開情報からは確認できません（当社も未確認です）。

使い始めるまでの準備：導入・接続・権限

導入と接続の手順

紹介ページと設定ガイドが示す流れは次のとおりです。

  1. ChatGPTの Plugins タブを開き、「ChatGPT Ads Manager」を探して詳細を開く
  2. ＋のボタンで導入し、案内に沿って権限を確かめ、必要な接続を済ませる（接続を導入時に求めるものと、初めて使うときに求めるものがあります）
  3. 新しいチャットを始め、やりたいことを書く。プラグインを指定したいときは「@」で呼び出す

Codex CLIでは「/plugins」でプラグインの一覧を開いて導入し、新しいセッションから使います。会社のワークスペースでは、管理者の設定や承認が必要な場合があり、使えないときはワークスペースの管理者に確認するよう、紹介ページは書いています。

権限は「Ads Managerの役割」で決まる

プラグインが扱えるのは、接続したAds Managerのユーザーがアクセスできるアカウントとリソースだけです。使える操作は、そのユーザーの役割と、アカウントで有効な機能によって変わります。

広告アカウントの役割は、アカウントごとに管理者（Admin）・メンバー（Member）・閲覧者（Viewer）の3つです。閲覧者は、書き込みやアカウントの管理の権限なしに見るだけの役割です。ChatGPTのワークスペースでの役割は、Ads Managerの権限にはなりません。 ワークスペースの管理者でも、広告アカウントの役割がなければ広告は操作できません。

広告案の下書きとプレビューは、アカウントを選ぶ前でもできます。画像のアップロードや広告の保存には、書き込みの権限があるAds Managerのアカウントが必要です。

プラグインでできること

ヘルプは、できることを7つに分けています。

分類

主な操作（ヘルプの記載）

アカウントの変更

サイトや説明文から広告を作る

タイトル・説明文の案。画像はサイトの画像、手元の画像、使える既存の素材、または選んだ場合に新しく生成。同じ画像・切り抜き・リンク先の標準広告を最大50本。既存のキャンペーン・広告グループへの追加や、足りない構成の作成

プレビューまではなし。保存は承認後

商品フィードから作る

使える商品フィードがあれば、キャンペーン・広告グループ・広告テンプレートを作る

承認後

キャンペーン・広告グループ・広告の管理

名前で探す、設定と状態の確認、作成、広告のプレビュー、対応する設定の更新、停止・有効化・アーカイブ、広告の画像の差し替え

確認はなし。変更は承認後

成果と成果イベントの分析

比較と順位づけ、表示回数・クリック・消化額・CTR・平均CPC・平均CPM、計測していれば帰属した成果、推移、時間・端末・国・下の階層での内訳、成果の計測元と設定、直近の生のイベント

なし

改善案のレビュー

有効なキャンペーンを1回、または毎日・毎週。準備・配信・計測を確かめ、予算・入札・ターゲティング・広告文・画像の改善の優先順位を、根拠と次の手順つきで示す

なし

配信しない原因の切り分け

アカウント→キャンペーン→広告グループ→広告→計測の順にたどり、最も手前の制約を特定する。確認できた事実と解釈を分けて、復旧の手順を示す

なし

アカウントの作成と管理

セルフサーブが使える地域で、自社の広告アカウントの作成を案内。ユーザーと招待中の一覧、招待、役割の変更、削除、ロゴの差し替え

承認後

分析では、期間を指定しないと、アカウントのタイムゾーンで直近の完了した7日間が対象になります。数字は、その時点でAds Managerにあるデータで、通常のレポートや帰属の遅れの影響を受けます。依頼にアカウント名やキャンペーン名と期間を入れると、結果が正確になりやすく、内部のIDは要らないとヘルプは書いています。

ロゴを差し替えると、新しいロゴはブランドの審査に回り、承認されるまで今のロゴが表示され続けます。

承認の仕組み：何が変わり、何が変わらないか

ヘルプは、情報を見ることと、変更することを分けて説明しています。

  • アカウントを変えないもの：アカウントのデータを読む、成果を分析する、原因を切り分ける、改善案のレビュー。広告案の下書きやプレビューも、アップロードや公開はしません
  • 承認が必要なもの：画像のアップロード、アカウント・キャンペーン・広告グループ・広告・ロゴ・ユーザーの権限の作成や更新。実行する操作そのものを確認します。アカウントの作成には、広告の規約（Advertising Terms）とプライバシーポリシーへの明示の同意も必要です
  • 承認の前に示されるもの：変更の対象のアカウント、今の状態、変更後の状態、変わる値。広告を作る場合は、LP・画像・文面・キャンペーンの設定・予算・ターゲティングなどです
  • 承認の後：内容が変わったら、改めて案を示して確認を求めます。更新が成功したら、対象を読み戻して結果を確かめます

広告は「確認した状態（status）で作る」と書かれています。作った広告をすぐに配信させたくない場合は、停止の状態で作るよう指示し、承認の画面で状態を確かめます（当社の提案）。

Codexから使う場合は、プラグインの承認に加えて、Codex側の実行環境（sandbox）と承認の設定も適用されると、設定ガイドは書いています。当社は、承認の確認を省く設定でこのプラグインを使わないことを勧めます。

逆に、次の操作は会話で済ませず、人が画面で確かめてから行うことを勧めます。

  • 公開・有効化：リンク先URLとパラメーター、配信する国、日付、予算の種類を確かめてから
  • 予算と入札の変更：日予算は日曜〜土曜の予算週の平均で、1日に最大で2倍まで使われます。金額の桁と、日予算か総額予算かを承認の前に読み上げて確かめます
  • ユーザーの招待・役割の変更：アカウントには少なくとも1人の管理者が必要です。代理店の担当者の追加や削除は、広告主の管理者が決めることを勧めます（当社の提案。分担は自社運用と代理店の分担の記事）

誤操作を防ぐ運用ルール（当社の提案）

  • 分析だけの担当者は、閲覧者（Viewer）の役割で接続します。 プラグインの操作は役割の範囲に限られるため、書き込みの権限がなければ、会話の途中で誤って変更が承認される余地を減らせます。ただし、グループ経由でより高い役割が付いていれば、高いほうの役割になります。実際の役割をAds Managerで確かめます
  • 依頼にはアカウント名と期間を必ず入れます。 複数の広告主のアカウントを見られる代理店は、承認の画面でアカウント名を毎回確かめます
  • 作った広告は停止の状態で保存し、Ads Managerで確かめてから有効にします
  • 変更は1回の依頼で1つにし、誰が・いつ・何を・なぜ変えたかを自社の記録に残します。 Ads Managerの設定には変更の記録（change logs）がありますが、変更の理由は自社の記録にしか残りません
  • 売上・ROASの報告には、プラグインの答えを使いません。 Ads Managerの列かCSVを使います
  • Codexでは、承認の確認を省く設定にしません

よくある質問

Q. プラグインが勝手に広告を変更することはありますか。 ヘルプは「ない」としています。画像のアップロードや、キャンペーン・広告などの作成・更新の前に、変更の全体を示して確認を求めます。毎日・毎週のレビューも読み取りだけで、提案に沿った変更は別に示されて承認が必要です。ただし、承認した内容は実行されます。承認の画面で、アカウント名と変更前後の値を確かめてください。

Q. 代理店が、複数の広告主のアカウントをまとめて扱えますか。 接続したAds Managerのユーザーがアクセスできるアカウントなら扱えます。権限は広告アカウントごとに付くため、広告主ごとに役割を付けてもらう必要があります。ChatGPTのワークスペースの役割は、広告アカウントの権限になりません。取り違えを防ぐため、依頼のたびにアカウント名を入れることを勧めます（当社の提案）。

Q. ROASを聞いても答えてくれません。 ヘルプによると、プラグインは成果の値（金額）を受け取らないため、売上やROASを出しません。ROASはAds Managerの Order Created ROAS の列で見ます。この列は order_created のイベントからだけ計算されるため、購入をこのイベントで送っているかも確かめます。

Q. プラグインで新しい広告アカウントを作れますか。 セルフサーブが使える地域では、事業者が自社の広告アカウントを作る手順を案内できるとヘルプは書いています。事業者・サイト・業種・国・通貨・タイムゾーンなどを入れ、規約に明示的に同意します。国・通貨・タイムゾーンは作成後に変えられないため、確定の前に確かめます。本人確認、請求、支払い、税などの準備はAds Managerで行います。

Q. 使うのに費用はかかりますか。 2026年10月29日時点で確認した資料には、プラグインの利用料金の記載は見当たりませんでした。紹介ページは、使えるかがプランとワークスペースの設定によると書いています。広告の費用は、どの方法で作った広告でも、配信に応じて広告費として請求されます。

まとめ

  • Ads Managerプラグインは、ChatGPT（Chat・Work）とCodexから会話でAds Managerを操作する仕組み。2026年9月16日に順次提供の開始を発表
  • 扱えるのは、接続したユーザーがアクセスできるアカウントと、その役割で許された操作だけ。ChatGPTのワークスペースの役割は権限にならない
  • 分析・レビュー・原因の切り分けは読み取りだけ。作成・更新は、変更前後の値を示して承認を得てから実行し、実行後に読み戻す
  • 1回の依頼で新しい広告は50本まで。請求・本人情報はAds Managerで行い、売上・ROASは出さない
  • 日本のアカウントでの提供状況と、使えるプランは未確認
  • 当社は「読む・下書きする」に使い、公開・予算・入札は人が画面で確かめる運用を勧める
