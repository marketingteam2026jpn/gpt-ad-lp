SEO会社の見積書の見方｜月額・本数・作業範囲で比べるポイント

企画・編集：GPT広告専門店（株式会社Ikigai）公開：2026年11月4日／情報確認：2026年11月4日

SEO会社の見積書は、月額の合計ではなく、記事の本数と工程、記事以外の作業、費用の種類、契約条件の4つに分けて比べます。

本記事の公式の記述は、Google 検索セントラル「Do you need an SEO?」（日本語版「SEO 業者の利用を検討する」）と Search Console ヘルプ（いずれも2026年11月4日に本文を確認）に基づいています。見積書の項目の整理と質問は株式会社Ikigaiの見解・提案です。契約や法令上の扱いは、別に確認してください。

この記事の要点

  1. 見積書は、月額の合計ではなく4つに分けて読みます。 記事制作（本数・文字数・工程）、記事以外の作業（リライト・内部対策・レポート・定例）、費用の種類（初期費用・月額・実費）、契約条件（最低期間・解約・成果物の権利・アカウントの名義）です。同じ月額でも、含まれる範囲が違えば比べられません。
  2. 見積書に書かれていない作業ほど、先に確かめます。 入稿・画像・リライトの本数・ツール費・解約後の記事の扱いは、書かれていないと後から追加費用や引き継ぎの問題になりやすい項目です（当社の見解）。
  3. Googleは、順位の保証をする業者に注意するよう書いています。 「Googleで1位を保証できる人はいない」とし、監査の段階では Search Console の読み取りの権限だけを渡すよう勧めています。LLMO（AIの回答への対策）が別料金なら、どの作業に対する費用かを1つずつ聞きます。

読んでほしい人：SEO会社から見積書を受け取った、または今の契約を見直したい企業のWeb担当・マーケティング責任者。
この記事で扱わないこと：公開されている料金の例はSEO・LLMO外注の費用相場、乗り換えの手順はSEO会社の乗り換え方で扱います。

見積書は4つに分けて読む

SEOの見積書は、会社ごとに書き方が違います。「SEO対策一式　月額◯円」のように1行で書かれていることもあれば、記事1本ごとの単価と月次の作業が細かく分かれていることもあります。比べる前に、どの見積書も同じ4つの箱に分け直すことを勧めます（当社の提案）。

箱

中身

分け直す理由

1. 記事制作

本数、文字数、構成・執筆・編集・入稿のどこまでか、画像、監修

月額のうち記事にいくら払っているかが分かる

2. 記事以外の作業

キーワード調査、記事計画、リライト、内部対策、技術的な助言、レポート、定例

記事の本数だけで比べると、ここの違いが見えなくなる

3. 費用の種類

初期費用、月額、単発の作業、ツール費などの実費

月額が低くても、初期費用や実費で総額が変わる

4. 契約条件

最低契約期間、自動更新、解約の通知期限、成果物の権利、アカウントの名義

乗り換えるときの費用と手間がここで決まる

1行の「一式」の見積書は、この4つの箱に何が入っているかを書面で出してもらうところから始めます。

記事制作の項目：本数だけで比べない

記事制作は、見積書で最も金額が大きくなりやすい部分です。本数が同じでも、次の項目で作業の量が変わります。

記事以外の作業：レポートと内部対策の中身

記事以外の作業は、見積書で「内部対策」「コンサルティング」「レポート」と短く書かれることが多い部分です。名前が同じでも中身が違うため、成果物の形で確かめます（当社の提案）。

項目

確かめること

キーワード調査・記事計画

毎月か初回だけか。計画の一覧（キーワード・題名・狙う読み手）を受け取れるか

リライト

月何本か、記事制作の本数に含むか。どの基準で対象を選ぶか

内部対策

題名・見出し・内部リンク・構造化データのどれを、誰が実装するか（提案だけか、実装までか）

技術的な助言

リダイレクト・表示速度・クロールの問題の調査を含むか。開発会社への作業の依頼は誰がするか

レポート

何の数字を、どの頻度で出すか（Search Console・GA4・順位）。次に何をするかの提案が付くか

定例

回数と時間、議事録の有無

相談

チャット・メールでの随時の相談を含むか

内部対策は「提案だけ」と「実装まで」で作業の量が大きく違います。Googleは、サーバーへのFTPのアクセスを持つ業者は、サイトに加えるすべての変更を進んで説明するべきだと書いています。CMSの権限を渡して実装まで任せる場合も同じ考え方で臨むことを勧めます（当社の見解）。変更の記録をどう共有するかも、見積もりの段階で決めておきます。

LLMOが別料金のとき：作業の重なりを確かめる

最近は、SEOの見積書とは別に「LLMO対策」「AIO対策」の費用が載ることがあります。Googleは、Google検索の観点では生成AI検索への最適化もSEOであることに変わりはないと書いており、作業の多くは通常のSEOと重なります（LLMO対策とは）。別料金の場合は、作業ごとに通常のSEOと重なるかを確かめることを勧めます（当社の提案）。

LLMOとして挙がりやすい作業

通常のSEOとの重なり（当社の見解）

聞くこと

AIクローラーの許可設定

robots.txt の点検の一部。一度決めれば頻繁に変える作業ではない

何を許可・拒否する方針か、その根拠

構造化データの整備

内部対策の一部。Googleは生成AI検索に構造化データは必須ではなく特別なマークアップもないとし、リッチリザルトのために使い続けるのはよいと書いている。Microsoft はスキーマの利用を勧めている

通常の内部対策の構造化データと何が違うか

引用されやすい書き方への書き換え

記事制作・リライトと重なる。Googleは AI 向けの書き直しは不要と書き、Microsoft は見出し・表・Q&Aで構造を整えることを勧めている

どの記事を、何を根拠に、何本書き換えるか

llms.txt の作成

Google 検索は使わないと明記している。使うサービスがあるかは確かめた範囲で判断

どのサービスで使われる想定か

AIの回答での表示の計測

Googleの表示回数は Search Console の生成 AI パフォーマンス レポートで見られる（通常のSEOで使う Search Console の中）。ChatGPTなどの回答は手作業の定点確認が中心になる

対象のAIサービス、質問の一覧、確認の頻度、報告の形

当社の見解では、追加の作業として実体があるのは、主にAIの回答での表示の計測（質問を決めた定点確認）です。測り方はAI回答での自社表示の測り方で扱います。それ以外の作業が別料金になっている場合は、通常のSEOの月額に含まれていないのかを確かめます。料金の公開例と、別料金にするかの論点はSEO・LLMO外注の費用相場で扱います。

費用の種類と契約条件

月額の比較だけでは、契約全体でいくらかかるかが分かりません。初期費用・実費・契約期間を足して、最低契約期間の総額で比べることを勧めます（当社の提案）。

項目

確かめること

初期費用

何の作業に対する費用か（サイトの調査、計測の設定、引き継ぎ）

ツール費

順位計測などのツールの費用を誰が払うか。契約を終えたあとにデータを引き取れるか

単発の作業

月額に含まれない作業の単価（追加の記事、画像、監修、サイトの改修）

最低契約期間

何か月か。期間中の解約の費用

自動更新・解約

自動で更新されるか。解約の通知は何日前までか

成果物の権利

記事・画像・構成案の権利が誰に帰属し、契約を終えたあとも使えるか

解約後の記事

契約を終えたときに記事を削除・非公開にする定めがないか

アカウントの名義

Search Console・GA4・CMS・順位計測ツールを、自社の名義で持てるか

成果物の権利と解約後の記事の扱いは、乗り換えのときに流入が落ちる原因になり得ます。記事が削除されたり、リダイレクトを設定せずにURLが変わったりすると、検索での評価を引き継げないことがあるためです（手順はSEO会社の乗り換え方）。契約書にどう書かれているかを確かめ、法令上の扱いは別に確認してください。

Googleが勧める確認：保証・権限・根拠

Googleの「Do you need an SEO?」のページは、SEO業者に依頼するときの注意を具体的に書いています。見積書を受け取った段階で使えるのは次の点です（要約）。

Googleが書いていること

見積書・提案書で確かめること（当社の提案）

Googleで1位を保証できる人はいない。順位を保証する、Googleとの「特別な関係」をうたう、「優先登録」を宣伝する業者に注意

順位・流入の保証や、Googleとの関係をうたう表現がないか

監査を受けるときは、内容をよく確かめ、Search Console は読み取りの権限だけを渡す（この段階で書き込みの権限は渡さない）

見積もりのための調査で、どの権限を求められているか

監査は、改善の現実的な見込みと、必要な作業の見積もりを示すもの

提案に、作業の量と、どの程度の改善を見込むかの根拠があるか

推奨の根拠に Google の公式の資料を挙げているか。AEO・GEOの助言は、生成AI機能の最適化の公式のガイドに沿っているか

LLMOの作業の根拠がどの資料か

サードパーティのツールは Google が評価・推奨しておらず、内部のランキングのデータにアクセスできない。「Googleに認められた」とうたうツールに注意

ツールの数字を、Googleの内部の指標のように説明していないか

何をするかを明確に説明しない会社に注意。最終的に、依頼した会社の行為の責任は自社にある

作業の中身と変更の記録を共有するか

SEO業者へのリンクを張る必要はない

契約の条件に、業者へのリンクの掲載が含まれていないか

Search Console には「読み取り専用」という名前のロールはありません。ヘルプによると、権限は所有者、フルユーザー（すべてのデータを見られ、一部の操作ができる）、制限付きユーザー（ほとんどのデータを見られる）に分かれ、ユーザーを追加・削除できるのは所有者だけです。ヘルプの対応表では、フルユーザーは URL の削除・サイトマップの送信・リンクの否認・再審査リクエストもでき、制限付きユーザーはこれらができないか、閲覧だけです。当社は、Googleの言う「読み取りの権限」に近いのは制限付きユーザーと考え、見積もりのための調査では制限付きユーザーを付け、所有者は渡さないことを勧めます（ロールの当てはめは当社の解釈です）。

同じページは、面談で聞くとよい質問として、過去の仕事の例、Google 検索の基本事項に従っているか、どんな結果をどの期間で見込み、成功をどう測るか、業界や地域での経験、サイトに加える変更をすべて共有し推奨の理由を詳しく説明するか、などを挙げています。

当社に見積書を送る場合

GPT広告専門店のSEO・LLMO運用では、お客様が現在SEO・LLMO業務に支払っている月額（税別）を基準に、同じ本数・同じ範囲を現契約の半額で引き受けています。条件は、現契約の見積書・請求書・契約書のいずれかがあること、現在の月額が税別30万円以上であること（広告費・サイト制作費は含みません）、記事制作が月30本以内であることの3つです。

月30本を超える記事制作、1本1万字を超える長文が中心の契約、多言語・10万ページ超のサイト、システム開発を含む契約、月30万円未満の契約、医療・金融など専門家の監修が毎本必要な領域、取材・撮影・動画の制作が大半を占める契約、作業範囲が見積書から判断できない場合は、個別に金額を提示し、半額にならないこともあります。初期費用・引き継ぎ費用はなく、最低契約は3か月（4か月目以降は1か月前の通知で終了）、表示はすべて税別です。SEOとLLMOを別メニューにせず、LLMO対応を理由にした追加請求はしません。検索順位・流入数・コンバージョン数・AI回答での表示や引用は保証しません。保証するのは、合意した本数と範囲を合意した月額で実行することです。

この記事で分からないこと

  • SEOの見積もりの相場や、記事1本あたりの標準の単価。 公式の統計はなく、本記事では平均や相場を作っていません。公開されている料金の例はSEO・LLMO外注の費用相場で扱います。
  • 契約の条項が法令上有効かどうか。 成果物の権利、解約の条件、途中解約の費用などは、契約書の文面と法令の両方で確かめる必要があり、本記事では解釈していません。
  • 見積書の作業で、どれだけ順位や流入が変わるか。 Googleは順位を保証できる人はいないと書いています。
  • LLMOの作業で、AIの回答での引用がどれだけ増えるか。 効果の大きさを示した公式の資料はありません。

よくある質問

Q. 見積書に「SEO対策一式」としか書かれていません。そのまま比べてよいですか。 比べる前に、作業の内訳を書面で出してもらうことを勧めます。一式のままだと、記事の本数、リライト、内部対策の実装、レポートの中身が分からず、他の見積書と同じ条件で比べられません。Googleも、何をするかを明確に説明しない会社に注意するよう書いています。

Q. 成果報酬型の見積もりはどう見ればよいですか。 何を成果とするか（順位・流入・問い合わせ）、どのキーワード・どのページを対象にするか、誰がどの数字で測るか、月の上限があるか、を確かめます。対象のキーワードを業者が選べる場合、成果が出やすい語に偏ることがあります（当社の見解）。Googleは、Googleで1位を保証できる人はいないと書いており、順位を保証する業者に注意を促しています。

Q. 見積もりのために Search Console の権限を求められました。渡してよいですか。 Googleは、SEO監査を受けるときは Search Console の読み取りの権限だけを渡し、この段階で書き込みの権限は渡さないよう勧めています。所有者の権限は、ユーザーの追加・削除や設定の変更ができるため、見積もりの段階では渡さないことを勧めます。当社の解釈では、読み取りに近いのは制限付きユーザーです（フルユーザーは URL の削除やサイトマップの送信もできます）。契約しなかった場合は、権限を外します。

Q. 月額が同じなら、記事の本数が多い会社を選ぶべきですか。 本数だけでは判断できません。Googleは自己評価の質問で、多くの書き手への外注などで1つ1つのページに手間がかけられていないか、多くの話題のコンテンツを大がかりな自動化で作っていないかを問うています。本数が多い見積書ほど、1本ごとの事実確認と、自社にしか書けない情報をどう入れるかを確かめます。

Q. 契約を終えたら、書いてもらった記事は使えなくなりますか。 契約の内容によります。記事・画像の権利が誰に帰属するか、契約を終えたあとも使えるか、削除や非公開の定めがないかを契約書で確かめてください。記事が削除されたり、リダイレクトなしでURLが変わったりすると、検索での評価を引き継げないことがあるため、見積もりの段階で確かめておく項目です。法令上の扱いは別に確認してください。

まとめ

  • 見積書は、記事制作・記事以外の作業・費用の種類・契約条件の4つに分けて読む
  • 記事は本数だけでなく、文字数の目安・工程・画像・修正・監修・AIを使う工程と確認の工程で比べる
  • レポート・内部対策・リライトは、成果物の形（何を、どの頻度で、提案だけか実装までか）で確かめる
  • 最低契約期間の総額、解約の条件、成果物の権利、アカウントの名義は、乗り換えの費用と手間を決める
  • Googleは順位の保証に注意を促し、監査の段階では Search Console の読み取りの権限だけを渡すよう勧めている
  • LLMOが別料金なら、作業ごとに通常のSEOとの重なりを確かめる
