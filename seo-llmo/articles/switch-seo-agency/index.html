SEO会社の乗り換え方｜引き継ぎで流入を落とさない手順

企画・編集：GPT広告専門店（株式会社Ikigai）公開：2026年11月4日／情報確認：2026年11月4日

SEO会社を乗り換えるときに守るのは、記事のURLと計測・CMSの権限です。URLを変えるならリダイレクトを1年以上、Search ConsoleやGA4は自社が管理者で持ち、旧会社の権限と確認トークンを外します。

本記事は、Google 検索セントラル（サイトの移転、リダイレクト）、Search Console ヘルプ、Google アナリティクス ヘルプ、タグマネージャー ヘルプの公式資料（いずれも2026年11月4日に本文を確認）に基づいています。乗り換えの段取りは株式会社Ikigaiの見解・提案です。契約の解釈は別に確認してください。

この記事の要点

  1. 乗り換えで守るのは、記事のURLと権限の2つです。 外注先を変えるだけでURLが変わらなければ、Googleの「URLの変更を伴うサイトの移転」の手順の対象にはなりません。URLを変える、記事を消す場合は、旧URLから新URLへの恒久的なリダイレクト（301・308）を設定し、Googleの資料が勧めるとおり、一般に少なくとも1年は残します。
  2. Search Console・GA4・タグマネージャー・CMSは、自社が管理者の名義で持ちます。 Search Console では、旧会社を所有者から外しても、確認トークンがサイトに残っていれば再び確認できるとヘルプに書かれています。外したあとにトークンも消します。
  3. 解約の通知期限から逆算して、引き継ぎを重ねます。 記事の削除や非公開の定め、成果物の権利、ツールのデータの扱いを契約書で確かめ、旧会社の作業が終わる前に新しい会社の引き継ぎを始めることで、空白期間を作らないようにします（当社の提案）。

読んでほしい人：SEOを外注している会社の変更を考えている企業のWeb担当・マーケティング責任者。
この記事で扱わないこと：見積書の比べ方はSEO会社の見積書の見方、費用の公開例はSEO・LLMO外注の費用相場で扱います。

乗り換えで流入が落ちる主な原因

外注先を変えたこと自体で検索の評価が変わる、という説明は Google の資料にはありません。当社の見解では、流入が落ちるのは、乗り換えに伴って、URL・ページ・設定・計測のどれかが変わったときです。Googleのサイトの移転の資料が「よくある間違い」に挙げる項目と、乗り換えで起きやすい場面を並べます。

個別の対応表を作らず、まとめてトップへ送る

新しいURLには自己参照の canonical、内部リンクとサイトマップは新しいURLへ

記事は移したが、内部リンクは旧URLのまま

計測のタグの外れ

（移転の資料の項目ではない。当社の整理）順位は変わらないが、分析ツールで流入が減ったように見える

旧会社のタグマネージャーのコンテナを外し、GA4のタグも消える

最後の「計測のタグの外れ」は、検索の評価とは関係なく、数字だけが落ちたように見えるものです。乗り換えの直後に流入が減ったときは、Search Console の検索パフォーマンス（クリック数）と、分析ツールの数字の両方を見て、どちらで減っているかを先に確かめます（当社の提案）。

Search Console の権限の引き継ぎ

Search Console の権限は、所有者（確認済み所有者・委任された所有者）、フルユーザー、制限付きユーザーに分かれます。ヘルプの説明の要点は次のとおりです。

権限

ヘルプの説明（要約）

確認済み所有者

HTMLファイルなどの確認トークンで所有権を確認した人。追加・削除にはサイト上のトークンの追加・削除が必要

委任された所有者

確認済み所有者がトークンなしで所有者にした人。ユーザー管理の画面で追加・削除できる

フルユーザー

すべてのデータを見られ、一部の操作ができる

制限付きユーザー

ほとんどのデータを見られる

ユーザーを追加・削除できるのは所有者だけです。プロパティには少なくとも1人の確認済み所有者が必要で、確認済み所有者がすべて外れると、残りのユーザーと委任された所有者も、猶予期間のあとで使えなくなります。データの収集は続きますが、誰かが所有権を確認するまで見られません。

乗り換えのときは、次の順で進めることを勧めます（当社の提案）。

  1. 自社の担当者が、確認済み所有者として自分の確認トークンで確認する（旧会社に頼らず、自社で確認できる状態にする）
  2. 新しい会社には、作業に必要な権限（フルユーザーなど）を付ける
  3. 契約の終了に合わせて、旧会社の担当者を外す
  4. 旧会社の確認トークンを消す

4が抜けやすい手順です。ヘルプは、所有者を外してもその人の確認トークンは削除・無効化されず、トークンが残っている限り、外された所有者は再び所有権を確認できると書いています。「未使用の所有権トークン」の一覧で残りを確かめられます。確認の方法がGA4やタグマネージャーの場合は、その人のGA4の編集の権限、タグマネージャーの Publish か Admin の権限を外すか、アカウントを切り替える必要があります。ただし、同じトークンを Merchant Center など他のサービスの確認にも使っていることがあり、消すと他のサービスに影響し得るとヘルプは注意しています。

GA4・タグマネージャーの引き継ぎ

GA4のロールは、管理者・編集者・マーケティング担当者・アナリスト・閲覧者に分かれます。ユーザーを管理できるのは管理者だけで、編集者はプロパティの設定を管理できますがユーザーは管理できません。ユーザーの削除にはアカウント単位の管理者のロールが必要です。

GA4のプロパティが旧会社のアカウントの中にある場合、ヘルプは、プロパティを別のアカウントへ移す機能を説明しており、移す理由の例に「新しい代理店に依頼したあと」を挙げています。

項目

一緒に移るもの

タグID、プロパティの設定、データストリーム、レポートのデータ（コピーではなく移動）、Google 広告などの連携

残るもの

移動前の変更履歴（移動元のアカウントに残る）

タグID（例：G-で始まるID）は変わらないので、タグを入れ直す必要はない

移せない場合の例

両方のアカウントの Google マーケティング プラットフォームの組織が違う、Google アド マネージャーと連携している、移動先のプロパティが上限（既定50）に達している など

移すには旧会社側のアカウントの権限も必要になるため、契約を終える前に依頼します。

タグマネージャーは、アカウントの権限（Admin・User）とコンテナの権限（Read・Edit・Approve・Publish）に分かれ、Publish はタグの公開まで行える権限です。乗り換えでは、自社が Admin と Publish を持ち、新しい会社には作業に必要な権限だけを付けます（当社の提案）。旧会社のコンテナを外すと、その中にあったGA4などのタグも動かなくなるため、外す前に中身を確かめ、必要なタグを自社のコンテナへ移します。

URLを変えるときの手順

新しい会社がCMSやURLの形を変える場合、Googleのサイトの移転の資料（URLの変更を伴う移転）に沿って進めます。要点は次のとおりです。

  1. 一度に1つずつ変える。 ドメインの変更、CMSの変更、デザインの変更を同時に行わず、1つずつ行うよう勧めています。
  2. 旧URLと新URLの対応表を作る。 サイトマップ、アクセス解析、Search Console のリンクのレポート、CMSの一覧などから重要なURLを集め、画像・動画・PDFも含めます。
  3. 恒久的なリダイレクトを設定する。 できればサーバー側の301・308を使い、リダイレクトのチェーン（転送の連続）を避けて最終の転送先へ直接送ります。
  4. 新しいURL側を整える。 自己参照の canonical、内部リンクの更新、新しいURLのサイトマップ。作業用の noindex や robots.txt のブロックを外します。
  5. テストして監視する。 URL検査ツールなどで転送を確かめ、新しいサイトマップを送信し、旧URLの索引が減って新URLが増えるかを見ます。

ドメインやサブドメインを変える場合は、Search Console のアドレス変更ツールも使います。HTTPからHTTPSへの変更、wwwの有無の変更、同じドメインの中のパスの変更には必要ありません。リダイレクトは「できるだけ長く、一般に少なくとも1年」残すよう書かれており、利用者の観点では無期限に残すことも検討するよう勧めています。

URLを変えると、一時的な順位の変動は起こり得ます。資料は、中規模のサイトでGoogleが新しいURLを表示し始めるまでに数週間以上、大きなサイトではさらにかかることがあると書いています。301などの恒久的なリダイレクトでPageRankが失われることはないとも説明しています。

解約と開始の時期を合わせる（当社の提案）

乗り換えで空白期間ができるのは、旧会社の作業が終わってから新しい会社を探し始める場合です。解約の通知期限から逆算して、次のように重ねます。

時期

やること

解約の通知期限の前

契約書で、通知期限・記事の削除や非公開の定め・成果物の権利・ツールのデータの扱いを確かめる。新しい会社の見積もりを取る

通知をしたあと

自社を Search Console の確認済み所有者、GA4・タグマネージャーの管理者にする。旧会社から一覧（記事・リダイレクト・構造化データ・設定）を受け取る

旧会社の最終月

新しい会社に権限を付け、引き継ぎと翌月の計画を始める。順位計測などのデータを書き出す

新しい会社の初月

旧会社の権限と確認トークンを外す。URLを変えた場合は、リダイレクトと索引を監視する

乗り換えと同時に、URLを変える大きな改修を始めないことも勧めます。Googleが「一度に1つずつ」と書いているとおり、外注先の変更とURLの変更を分けたほうが、流入が変わったときに原因を切り分けやすくなります。

当社の場合の流れ

GPT広告専門店のSEO・LLMO運用では、現契約の解約月に合わせて開始日を決め、空白期間を作らない進め方をとっています。引き継ぎ作業は終了月の前月から始めます。初期費用・引き継ぎ費用はなく、最低契約は3か月です（4か月目以降は1か月前の通知で終了）。

段階

内容

STEP 1（当日〜2営業日）

現契約の見積書・請求書・契約書のいずれかを送っていただき、半額の対象かどうかと概算の月額を返信

STEP 2（1週目）

30分の確認ミーティング。作業範囲・サイトの状況・解約の時期を確かめ、正式な月額と、引き継ぎに必要な権限（Search Console・GA4・CMS）を伝える

STEP 3（2〜3週目）

既存記事の棚卸し、キーワードの引き継ぎ、計測環境の設定、AI回答での現状の計測。初月の記事計画を出し、承認後に制作を始める

STEP 4（毎月）

計画どおりに記事を納品し、Search Console・GA4・AI回答の計測結果を報告。翌月の計画を定例で決める

半額の条件（現在の月額が税別30万円以上など）と例外は、SEO・LLMO運用のページに記載しています。検索順位・流入数・コンバージョン数・AI回答での表示や引用は保証していません。

この記事で分からないこと

  • 乗り換え後に順位がどれだけ動くか。 URLを変えない場合の影響を示した公式の資料はありません。URLを変える場合も、Googleは期間の目安（中規模で数週間以上）を示すだけです。
  • 確認トークンを消したときに、他のサービスに出る影響。 ヘルプは、同じトークンを他のサービスで使っていると影響し得ると注意していますが、どのサービスにどう影響するかはサイトごとに確かめる必要があります。
  • ドメイン・サーバーの名義の移管の手順。 契約先（レジストラ・ホスティング会社）ごとに違い、本記事では扱っていません。
  • 順位計測などのツールのデータを引き継げるか。 ツールと契約の名義によります。
  • 契約の条項（記事の削除・権利）の法令上の扱い。 本記事では解釈していません。

よくある質問

Q. 旧会社が、契約を終えたら記事を削除すると言っています。 契約書で、記事の権利が誰に帰属し、契約の終了後も使えるか、削除の定めがあるかを確かめてください。記事が削除されると、そのURLからの検索の流入は見込めなくなります。同じURLで記事を残せるかを交渉するのが、検索の面では最も影響が小さい方法です（当社の見解）。法令上の扱いは別に確認してください。

Q. 乗り換えた翌月に流入が減りました。何から確かめればよいですか。 まず、Search Console のクリック数でも減っているかを見ます。Search Console では減っておらず分析ツールだけで減っている場合は、計測のタグが外れた可能性があります。Search Console でも減っている場合は、URLの変更・記事の削除・noindex・robots.txt・リダイレクトの順に確かめます（当社の提案）。URLを変えた場合は、一時的な変動は起こり得るとGoogleは書いています。

Q. Search Console が旧会社の担当者の名義で作られていました。過去のデータは見られますか。 Search Console のデータはサイトのプロパティに対して集められています。ヘルプによると、確認済み所有者がいなくなってもデータの収集は続き、誰かが所有権を確認すれば見られるようになります。自社の担当者が自分の確認トークンで確認済み所有者になれば、同じプロパティのデータを見られます。旧会社の担当者を外すのは、その後にします。

Q. 乗り換えのついでに、サイトのリニューアルもしたいです。 Googleは、ドメイン・CMS・デザインの変更を同時に行わず、1つずつ行うよう勧めています。外注先の変更とリニューアルを同じ時期にすると、流入が変わったときに原因を切り分けにくくなります。リニューアルでURLが変わるなら、対応表とリダイレクトの計画を先に作ります。なお、Googleは、SEOの専門家に依頼するよい時期として、リニューアルを考えているとき（早いほどよい）を挙げています。

Q. 旧会社の権限は、いつ外せばよいですか。 旧会社の作業が終わる日（契約の終了日）に合わせて外すことを勧めます（当社の提案）。早すぎると旧会社が最後の作業をできず、遅すぎると契約外の変更が起こり得ます。GA4のプロパティを旧会社のアカウントから移す場合は、移したあとに外します。Search Console は、確認トークンの削除までを1つの作業として行います。

まとめ

  • 外注先を変えたこと自体で評価が変わるという説明は Google の資料にない。流入が落ちるのは、URL・記事・設定・計測が変わったとき（当社の見解）
  • 記事のURLを変えない・消さないのが、最も影響が小さい。変えるなら301・308の恒久的なリダイレクトを、一般に少なくとも1年
  • Search Console・GA4・タグマネージャー・CMSは、自社が管理者の名義で持つ。Search Console は旧会社を外したあとに確認トークンも消す
  • GA4のプロパティは別のアカウントへ移せる。タグIDは変わらず、タグの入れ直しは不要（両方のアカウントで管理者と編集者のロールが必要）
  • 解約の通知期限から逆算して、引き継ぎを重ねる。URLを変える改修は乗り換えと分ける
